1. Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
Jawab: Keuntungan dari memisahkan header dan footer menjadi file component tersendiri adalah kode yang sama cukup ditulis satu kali saja dan dapat dipakai di banyak halaman. Contohnya, jika suatu saat menu navigasi atau teks footer perlu diubah, kita cukup mengedit satu file di folder component, tidak perlu membuka setiap halaman satu per satu. Kemudian, tampilan semua halaman tetap konsisten dan rapi karena perubahannya otomatis berlaku di semua halaman. Selanjutnya, file seperti index.php jadi lebih pendek dan rapi.

2. Perhatikan halaman-halaman admin (Buku, Kategori, Penulis, Pengguna, Profil) pada Bagian 2 - bagian mana pada halaman-halaman tersebut yang mengalami masalah yang sama seperti header/footer sebelum dipisah?
Jawab: Bagian yang mengalami masalah yang sama adalah sidebar dan topbar. Keduanya masih ditulis ulang di setiap halaman admin, sehingga kalau ingin menambah atau mengubah menu, kita harus mengedit banyak file satu per satu. Hal ini bisa membuat kita lupa mengubah salah satu file atau salah ketik. Solusinya adalah membuat sidebar dan topbar menjadi component di components/admin/, lalu dipanggil menggunakan require_once di setiap halaman.
